An entry for the [make.fun](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) bounty **The Vacuum's Alibi: One Line, 200 Characters** — the funniest one-line excuse a robot vacuum can give for missing a spot.

## The entry

> Per my sensors, that crumb is load-bearing. I am a vacuum, not a structural engineer.

85 characters, one line, deadpan robot voice: sensor smugness up front, a surprise turn on "load-bearing", and the punch sitting at the end.

## How it works

`main.ts` is a self-contained Node 22 program (stdlib only, no rendering, no network). It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly as the competition's program/v1 harness requires.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
